# Silhouette — a daily country guessing game

Every day there's a new mystery country, shown only as a blank, single-colour outline with no names.
You get **6 guesses**. Each wrong guess shows how far away (km), which direction, and how close (%) you were,
and unlocks a new clue:

1. Region & hemisphere
2. The map zooms out to reveal the (unlabelled) neighbouring countries, plus border/coastline info
3. Size: area, a comparison and its size rank
4. Languages, currency and the capital's first letter
5. The flag

Progress, stats and streaks are saved in the browser (`localStorage`), and you can share an emoji summary of your result.

## Play

It's a fully static site with no build step: open `index.html` in a browser, or serve the folder
(`npm start`) or host it on GitHub Pages.

Use `?date=YYYY-MM-DD` to play a specific day (handy for testing).

## How the daily country is chosen

All countries big enough to see at map resolution (≥ 500 km², 181 of them) are shuffled once with a fixed seed.
Day *n* since 1 Jan 2026 (in the player's local time) gets entry *n* mod 181, so everyone gets the same country
on the same day and no country repeats until all have been used. Tinier countries can still be guessed.

## Data

`data/` is generated by `npm install && npm run build:data` from
[world-atlas](https://github.com/topojson/world-atlas) (Natural Earth 1:50m shapes) and
[world-countries](https://github.com/mledoze/countries) (metadata). Flags load from [flagcdn.com](https://flagcdn.com).
Rendering uses [d3-geo](https://d3js.org) and [topojson-client](https://github.com/topojson/topojson-client), vendored in `vendor/`.
